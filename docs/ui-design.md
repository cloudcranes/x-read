# x-read UI 设计系统与落地说明

> 适用对象：`android/app/src/main/java/com/alanmaster/xread/ui/` 下的 Compose 界面。
> 适用范围：书架、发现（榜单/分类）、搜索、书籍详情、目录、阅读页（正文 + 工具栏 + 设置浮层）、书评、作者页。
> 约束：**不改动后端与 API 契约**；不引入新依赖；Material3 为唯一 UI 基础。

---

## 1. 现状审计：动手前先说清楚哪里不对

以下问题是在通读 `Theme.kt / ReaderPalette.kt / Components.kt` 与 13 个页面后实测出来的，
每条都对应代码里的具体位置。

### 1.1 视觉语言整体是「凑」出来的，没有系统

| 症状 | 证据 | 后果 |
|---|---|---|
| 字号没有阶梯 | 全项目出现 9.5 / 10 / 10.5 / 11 / 11.5 / 12 / 12.5 / 13 / 13.5 / 14 / 15 / 17 / 18 / 20 / 22 / 24 sp 等十几档 | 「小字堆」与「大字跳跃」并存，同一屏里 11sp 与 15sp 相邻，没有节奏 |
| 字重只有两档 | `FontWeight.Bold` 与 `FontWeight.SemiBold` 混用，没有 Medium/Normal 的分层 | 标题、卡片名、正文、辅助信息靠「Bold 与否」区分，主次拉不开 |
| 间距是散值 | `14.dp` 出现 38 次、`8.dp` 36 次、`12.dp` 27 次、`6.dp` 24 次、`10.dp` 21 次……外加 `4/2/5/7/11/13/18/34` 等一次性值 | 没有网格，无法横向对齐；页面之间左右边距各不相同（14 / 12 / 16 混用） |
| 圆角是散值 | 全项目只有 `8.dp / 10.dp / 6.dp / 4.dp` 四种 | 封面 8dp、分类块 10dp、角标 6dp、作者徽标 4dp，同一屏四种圆角，视觉噪点高 |
| 分隔线与占位底同色 | `DividerLine()` 用 `outline`，占位封面用 `surfaceVariant` | 层级混乱：读者分不清「线」和「块」 |

### 1.2 色板

- **只有一个 `surface` 系列**。`surface` 与 `surfaceVariant` 在浅色下分别是 `#EEE5CF` 和 `#EEE5CF`——**同一个值**，
  所以「卡片底」和「占位底」和「分割线」在视觉上无法区分（`Theme.kt:20-30`）。
- **`background` 与 `surface` 语义倒挂**：`background = #F8F4EA`（米黄），`surface = #EEE5CF`（更深的米黄）。
  在 M3 语义里 `surface` 应当比 `background` 更「上层」，这里却更下沉。
- **`tertiary` / `error` / `secondary` 未定义**，全部退回 M3 默认紫/红。
  结果是阅读页里「朗读中」的底色和「高亮」的底色用的是同一套紫色系，与米黄正文打架。
- **阅读页配色与应用配色是两套独立的东西**（`ReaderPalette.kt`），这是对的，但阅读色只有 3 个槽位
  （bg / text / title），**没有次要色、没有强调色、没有分割线色**。
  于是阅读页里凡是「弱信息」都只能去借 `MaterialTheme.colorScheme.onSurfaceVariant`——
  那是从米黄应用底色推导出来的，跟当前阅读底色（可能是纯白、可能是浅绿）不匹配。

### 1.3 阅读页（问题最集中）

| 问题 | 位置 | 说明 |
|---|---|---|
| **不沉浸** | `ReaderScreen.kt` 全程 `Scaffold` 常驻顶栏 + 底栏 | 顶栏 6 个控件、底栏 4 个控件永久占屏，阅读可视高度只剩约 55% |
| **顶栏塞了字号按钮** | `TextButton("A-")` / `TextButton("A+")` | 字号调节挤在顶栏，与查找、书签、目录并列，7 个动作里没有一个是「主要动作」 |
| **工具栏颜色与正文底色脱节** | `containerColor = MaterialTheme.colorScheme.background` | 选「夜色」阅读底时，顶栏仍是应用浅色米黄 → 白底黑字夹着深色正文，像两张图 |
| **正文用无衬线** | `Text(p, fontSize = fontSize.sp, ...)` | 中文网络小说是长文本，无衬线在米黄底上笔画过重，夜间尤其明显 |
| **段间无呼吸** | `Spacer(Modifier.padding(bottom = 12.dp))` | 12dp 在 19sp 正文里偏挤；且用 `padding` 而不是 `height`，语义混乱 |
| **无首行缩进也无段间距规范** | — | 中文小说按「段」组织，两者都没有，段落糊成一片 |
| **高亮底色用 primary 叠加** | `MaterialTheme.colorScheme.primary.copy(alpha = 0.14f)` | primary 是赭石色，叠在米黄上偏脏；且在夜色下变成棕色块 |
| **设置浮层不存在** | 字号只有顶栏两个 `TextButton` | 用户找不到行距、背景、翻页方式；`SettingsSheet` 是全局设置弹窗，与阅读页不在一个上下文里 |

### 1.4 书架

- **信息密度错位**：书架与「猜你喜欢」共用同一个 `LazyVerticalGrid`。
  书架里的书有**分组、新章数、阅读进度**这些状态，竖排网格放不下，只能挤成一个 10.5sp 的小字尾巴
  （`ShelfScreen.kt:176`），且「↑ 新至 N 章」和分组名抢同一个位置。
- **状态色用错**：`↑ 新至 N 章` 用 `primary`（赭石），分组名用 `onSurfaceVariant`，两者字号相同 10.5sp，
  视觉权重却差很多，看起来像两级信息其实是一级。
- **排序与分组的入口位置不定**：排序芯片在「继续阅读」标题之后、分组芯片在排序芯片之后，
  但两者都是作用于同一批书，视觉上像是两个不同的列表头。
- **热词在顶部裸奔**：一排 `SuggestionChip` 直接顶在标题栏下，没有标题说明它是什么。

### 1.5 详情页

- **三个等宽按钮平铺**：「开始阅读」「加入书架」「下载」「前20章」四个动作分成三行 `OutlinedButton`，
  主次不分；「前 20 章」独占一行。
- **元信息是一串 `·` 连接的字符串**：「作者 X · 评分 8.5 · 100 万字 · 玄幻」，
  读者必须逐段解析才能取出「评分」。
- **章节目录被截断到 12 章且无标题**，与上方的「相关推荐」在视觉上连成一片。

### 1.6 其它

- 顶栏标题一律 `FontWeight.Bold`，中文在 Bold 下笔画会糊；字号 20sp（M3 默认 titleLarge）在一行里过于突出。
- 搜索框塞在 `TopAppBar` 的 `title` 槽里，输入框宽度被返回键挤到只剩 60%。
- 目录页当前章只靠**文字颜色**区分（`primary` vs `onBackground`），色弱用户无法分辨。
- 书评页头像 34dp、正文 13.5sp——正文字号小于详情页的元信息 12sp 但行距 21sp，
  长评展开后一屏全是文字，没有段落呼吸。
- 目录页 `目录 · 书名（1234 章）` 挤在一个 `TopAppBar.title` 里，必然截断。

## 2. 设计系统

三层结构，互不越界：

```
色板  ColorScheme / ReaderPalette   ← 做什么颜色
字体  Typography + Serif            ← 什么字、多大
尺度  Space / Radius / Elevation     ← 多大、多圆、多高的层级
```

### 2.1 色板

#### 2.1.1 应用外壳（`Theme.kt`）

**浅色「宣纸」** — 暖白底 + 赭石主色：

| 角色 | 值 | 用途 |
|---|---|---|
| `background` | `#FAF6F0` | 页面底 |
| `surface` | `#FFFFFF` | 卡片（比 background 亮 = 更上层，修正旧实现的倒挂） |
| `surfaceVariant` | `#F0E9DE` | 占位底 / 输入框底 |
| `surfaceContainerLow` | `#F6F1E9` | 底部弹层 |
| `surfaceContainer` … `Highest` | `#F1EAE0` → `#E4D8C9` | 五级容器深度 |
| `primary` | `#9C4A22` | 唯一强调色：主按钮、选中态、状态标 |
| `onSurfaceVariant` | `#6B6055` | 弱信息（说明、计数、次要文案） |
| `outline` / `outlineVariant` | `#D9CFBE` / `#E7DFD2` | 分割线与描边（描边用更浅的那个） |
| `error` | `#B3261E` | 错误 |

**深色「夜灯」** — 近黑暖灰底 + 浅赭主色：

| 角色 | 值 |
|---|---|
| `background` | `#14120F` |
| `surface` | `#1C1A16` |
| `surfaceVariant` | `#26231E` |
| `primary` | `#E3A47C` |
| `onSurface` | `#E8E1D6`（**不用纯白**，减少眩光） |
| `onSurfaceVariant` | `#B5ABA0` |

深色下主色提亮到 `#E3A47C` 是必要的：赭石 `#9C4A22` 在近黑底上对比度只有 3.4:1，达不到文字标准。

**二级/三级色**：`secondary` 用鼠尾草绿（灰绿，弱于 primary），
`tertiary` 用暗金（只用于「朗读中」这类提示），两者都不与 primary 抢注意力。

#### 2.1.2 阅读页（`ReaderPalette.kt`）

阅读底色**必须由用户显式挑选**，不跟随系统——这是产品约束：
跟随系统意味着系统深色时无法保留米黄，而米黄恰恰是护眼的关键。

| 方案 | 底色 | 正文 | 标题 | 次要 | 强调 | 理由 |
|---|---|---|---|---|---|---|
| 米黄 `paper` | `#F3EBD9` | `#2C2620` | `#1A1611` | `#7B6E5E` | `#9C4A22` | **默认**。带黄绿的底抵消短波蓝光；正文用深褐而非纯黑 |
| 白 `white` | `#FFFFFF` | `#1F1D1A` | `#0C0B0A` | `#75706A` | `#9C4A22` | 白天/OLED 省电 |
| 浅绿 `mint` | `#E4EEDE` | `#1E2820` | `#131C16` | `#66756A` | `#4A6B3F` | 进一步削弱红光，白天强光下用 |
| 夜色 `dark` | `#171A1E` | `#C8C7C2` | `#EBEAE5` | `#8A8C90` | `#D9A273` | **深灰蓝底而非纯黑**：纯黑↔白字对比度 21:1 过高，OLED 上还有拖影；深灰底配浅灰字约 8:1 |

`auto`（跟随系统）→ 系统深色映射到 `dark`，浅色映射到 `paper`。**不能**映射到 `white`。

阅读色板扩展到 7 个槽位（比旧版的 3 个多 4 个），所有「弱信息」从阅读色板取，
不再借应用的 `colorScheme`——否则浅绿底上会出现米黄色的说明文字。

### 2.2 字体阶梯

中文的字面框比西文满，同样的 pt 看着更大，因此基准比 M3 默认**低一档**；
行高按中文行文取 1.5–1.75 倍。

| 角色 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `headlineMedium` | 24 / 32 | Bold | 大标题（暂未使用） |
| `titleLarge` | 18 / 26 | Bold | 详情页书名 |
| `titleMedium` | 16 / 24 | SemiBold | 区块标题、顶栏副标题 |
| `titleSmall` | 14 / 20 | SemiBold | 小标题 |
| `bodyLarge` | 15 / 24 | Normal | 列表正文 |
| `bodyMedium` | 14 / 21 | Normal | 描述、书评正文 |
| `bodySmall` | 12 / 18 | Normal | 弱信息 |
| `labelLarge` | 14 / 20 | Medium | 按钮 |
| `labelMedium` | 12 / 16 | Medium | 芯片、标签 |
| `labelSmall` | 11 / 15 | Medium | 角标、计数 |

**两套字族**：

- `Sans`（无衬线）— 所有界面文本。
- `Serif`（衬线）— **仅阅读页正文与章节标题**。Android 上 `FontFamily.Serif` 映射到 Noto Serif，
  中文回退到思源宋体，横向笔画更细、更均匀，米黄底与夜色底上正视疲劳明显低于黑体。

**中文排版规则**：

1. 行距：正文 1.75（可调 1.2–2.4），标题 1.45。
2. 正文左右留白 24dp（比界面页边距 16dp 更宽）——行太长反而不易读。
3. **段间用 12dp 空行分隔，不用首行缩进**：网络小说按「段」组织，空行更符合阅读习惯。
4. 章节标题与正文之间加一条 28×2dp 的短横线作为分隔（不是一整条 divider）。
5. 数字、评分、字数等**辅助数据用 `labelSmall` 11sp + `onSurfaceVariant`**，
   绝不与正文同号——正文区里出现第二个 15sp 就会争夺注意力。

### 2.3 尺度

**间距**（4dp 基网格，`Space` 对象）：

```
xxs=2  xs=4  sm=8  md=12  lg=16  xl=20  xxl=24  huge=32
gutter=16   页面左右安全边距
card=12     卡片内边距
```

**圆角**（`Radius` 对象）：

```
xs=6   芯片 / 标签 / 徽标
sm=8   封面 / 输入框 / 小卡片
md=14  通用卡片 / 面板
lg=18  浮层 / 空态块
xl=24  底部抽屉顶部
```

**阴影**（`Elevation` 对象）——**只有两级**：

```
flat   = 0.dp    贴面：卡片
raised = 6.dp    浮起：浮层 / 抽屉 / 弹出菜单
```

### 2.4 组件规范

| 组件 | 规范 |
|---|---|
| **封面** `BookCover` | 圆角 `Radius.sm`（详情页用 `md`），比例 0.70（比 0.72 更接近常见小说开本），占位用 `surfaceContainerHigh` + 书名首字 |
| **网格卡片** `BookCard` | 封面 + 书名（13sp SemiBold，2 行）+ **一行**元信息（作者 · 章数，11sp 弱色）。元信息只留两段，更多状态交给专用卡片 |
| **书架卡片** `ShelfBookCard` | **横排**：68dp 封面 + 右侧书名/作者/主状态/次状态。1dp `outlineVariant` 描边、圆角 `Radius.md` |
| **主按钮** `PrimaryButton` | 实心 `primary`，高 48dp，圆角 `Radius.sm`，文字 15sp SemiBold。**一个页面最多一个** |
| **次按钮** `SecondaryButton` | 描边 1dp `outlineVariant`，高 48dp，文字 14sp |
| **单选芯片** `SelectChip` | 选中 = `primaryContainer` 底 + `primary` 描边；未选 = `surface` 底 + `outlineVariant` 描边。高 32dp 左右 |
| **标签** `Tag` | 三态：默认（`surfaceContainerHigh`）/ 强调（`primaryContainer`）/ 实心（`primary`）。10sp |
| **区块标题** `SectionHeader` | 标题 16sp SemiBold + 右侧弱说明或「更多」。**不用底色块**——底色块会把长页面碎成一段段 |
| **空态** `EmptyHint` | 主文案 14sp + 可选行动按钮。**必须说明下一步**，不能只有一行灰字 |
| **顶栏** `XReadTopBar` | 标题 16sp **SemiBold**（不是 Bold——中文 Bold 笔画会糊），可选副标题 11sp 弱色 |
| **底部弹层** `BottomSheet` | 顶部 32×4dp 拖拽条 + 圆角 `Radius.xl` + `surfaceContainerLow` 底 + 6dp 阴影 |

### 2.5 图标风格

- 统一用 Material Icons **Filled**（`material-icons-extended` 已在依赖里）。
- 尺寸 20dp（顶栏）/ 15dp（入口芯片）。
- **不用 emoji 当图标**：`🔖` `💬` `👍` `⏸` `▶` 在不同渲染器下字形与基线都不同，
  且不能改色。旧代码里的 `Text("🔖")`、`Text("享")`、`Text("榜")` 全部换成真图标或文字按钮。
- 颜色继承 `onSurfaceVariant`，仅「主要动作」用 `primary`。

## 3. 落地：各页面的具体改动

### 3.1 阅读页（改动最大）

**结构**：默认**全屏无顶栏无底栏**，只有正文 + 顶部 2dp 进度线。
点按屏幕**中央 40%** 唤出/收起工具层；左右各 30% 仍是翻页。

```
┌────────────────────────────┐
│ ▬▬▬▬▬▬▬░░░░░░░░  进度线 2dp │  ← 常驻
│                            │
│      第十二章 山雨欲来      │  ← Serif Bold, fontSize+4
│      ──                      │  ← 28×2dp 短横线
│      正文第一段，衬线……     │  ← Serif, 19sp/33sp, 左右 24dp
│                            │
│      正文第二段              │  ← 段间 12dp 空行
│                            │
└────────────────────────────┘
```

**工具层**（点中央才出现，带滑入滑出动画）：

- **顶栏**：返回 · 章节标题（省略）· 查找 · `Aa`（字号）· 目录。
  颜色全部取自**当前阅读色板**，不再是 `MaterialTheme.colorScheme.background`——
  这是旧实现「选夜色后顶栏仍是白底」的根因。
- **底栏**：上一章 · 进度百分比 · 朗读 · 下一章。
  朗读中时上方浮出倍速条（1x / 1.5x / 2x / 15分 / 取消定时），可横向滚动。
- **设置浮层**：点 `Aa` 唤起，底部升起。含
  - 字号：**用一行中文预览**（「永夜与孤灯」），不是只给数字——数字看不出效果；
  - 行距：紧 / 松 / 数值；
  - 背景：**四个色块预览**（方块里渲染一个「文」字），选中描 2dp 强调色；
  - 点按左右翻页、音量键翻页两个开关。

### 3.2 书架（信息密度）

- 书架改为**横排卡片列表**（`LazyColumn` + `ShelfBookCard`），不再与推荐流共用网格。
  同样一屏能放下 4 本而不是 2 本。
- 卡片状态行分两级：
  - **主状态**（11sp SemiBold）：有更新时 `↑ 新至 N 章` 用 `primary`；否则显示分组名（弱色）；
  - **次状态**（11sp 弱色）：`本章第 N 段`。
- 段落下标是**章内**序号，所以明确写「本章第 N 段」——写成「第 N 段」会让人以为是全书序号。
- 「榜单 / 分类 / 离线」三个入口从顶栏的 IconButton（原本是「榜」「类」「离」三个单字）
  提到正文顶部，做成三张等宽入口卡。
- 排序与分组芯片合并到同一个区块内，视觉上不再像两个列表头。
- 推荐流用**嵌套网格**（`LazyVerticalGrid` 嵌在 `LazyColumn` 里，高度按行数估算），
  而不是像旧代码那样把网格和列表混在一个 `LazyVerticalGrid` 里。

### 3.3 详情页

- **一个主按钮**（实心「开始阅读 / 继续阅读」）+ 两行描边次按钮。
- 元信息从 `·` 连接的字符串改成**标签组**：评分（强调）、分类、万字、章数。
- 章节列表从 12 章减到 8 章，标题独立成区块并带「全部 →」入口。

### 3.4 其它页面

- **搜索**：搜索框从 `TopAppBar.title` 移到标题栏**下方独立一行**，输入框拿到完整宽度。
- **榜单**：顶栏标题 + 副标题（「番茄榜单 / 新书榜」）两级；榜种与分类两条芯片行。
- **分类**：筛选框统一样式；分类块从固定 3 列改为 `Adaptive(108.dp)`。
- **目录**：顶栏标题「目录」+ 副标题「书名 · 1234 章」；当前章用**左侧 3dp 竖条 + 主色文字**双重标记，
  并在右侧显示序号；筛选框统一样式。
- **书评**：顶栏标题「书评」+ 副标题书名；汇总行改为「弱化数字 + 强调说明」；
  头像 34dp、正文 13.5sp/21sp 保留（长评需要更松的行距），折叠逻辑不变。
- **作者**：头像 60dp，名字 18sp，粉丝与作品数走弱色副行。
- **设置**：字号/行距/背景与阅读页浮层同语义，背景同样用**色块预览**。

## 4. 未验证 / 待办

- 本次改动**只做了编译验证**，没有在真机或模拟器上跑过截图。
  视觉效果（尤其是米黄底 + 衬线正文的实际观感、夜色模式的对比度）需要实机确认。
- 嵌套 `LazyVerticalGrid` 在 `LazyColumn` 里的高度是**按「每行 4 本 × 210dp」估算**的。
  封面比例变化或列数变化时这个常数要跟着改，否则推荐区底部会被裁掉。
- 阅读页「点中央唤出工具栏」改变了原有的点按语义：
  旧实现中央 40% 区域点了**什么都不做**，现在会唤出工具栏。符合常见阅读器预期，但属于行为变更。
- `SectionHeader` 的 `action` 与 `hint` 二选一（同一位置），没有同时显示两者。
- 夜间色的 `ReaderPalette.dark` 是按 8:1 对比度估算的，没有用取色器实测验证。
- 未改动 `ToolsScreen.kt` / `MarksScreen.kt` / `AudioScreen.kt` 的内部排版，
  它们仍使用旧的散值间距（`14.dp` / `11.sp`），与新系统的 `Space.gutter` 不完全一致。
