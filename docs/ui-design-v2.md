# x-read UI 设计 v2：「纸间」

> 目标设备：1080×2400 / 440dpi（392.7 × 872.7 dp），Android 10+，Material3 + Jetpack Compose。
> 本文是**设计规格**，不是代码。落地时对 `android/app/src/main/java/com/alanmaster/xread/ui/` 负责，
> 令牌全部沿用现有 `Theme.kt`（`Space` / `Radius` / `AppTypography` / `LightColors` / `DarkColors`）与
> `ReaderPalette.kt`，只做收敛与细化，不另起平行系统。
> 设计图：`dsh-image-gen/image-1891b21a.jpg`（书架）、`image-55b3f07d.jpg`（发现）、
> `image-f19cf934.jpg`（详情）、`image-f1e6fceb.jpg`（阅读·米黄）、`image-ae49f06c.jpg`（阅读设置）、
> `image-50191b86.jpg`（阅读·夜色）。

## 1. 设计方向

**「纸间」= E-Ink/Paper 骨架 + 中文编辑设计排布 + 单一暖色强调。**

取 `styles.csv` 的 `e-ink-paper`（Paper-like / matte / high contrast / calm / slow tech）作为骨架，
`products.csv` 的 Book & Reading Tracker 配色焦点（warm paper white + ink brown）作为色板依据。
这条方向与现有实现的「宣纸 + 赭石」一脉相承，不推翻已验证的阅读配色，只解决三件事：

1. **层级靠线，不靠阴影。** 卡片 1px 发丝线（`outlineVariant`）+ 白面，永远不使用投影堆叠。
2. **封面是第一信息。** 所有书籍出现的地方，3:4 封面占比不低于该行高度的 60%，文字让位。
3. **界面无衬线、正文有衬线。** 界面一律 Noto Sans SC，阅读正文一律 Noto Serif SC；两条轨道不交叉。

反模式（明确禁止）：渐变、玻璃拟态、彩色投影、emoji 当图标、同屏三种以上圆角、纯黑纯白阅读底。

## 2. 设计令牌

### 2.1 颜色角色（应用外壳）

| 语义 | 浅色（宣纸） | 深色（夜灯） | 用途 | 实测对比度 |
|---|---|---|---|---|
| `background` | `#FAF6F0` | `#14120F` | 页面底 | — |
| `surface` | `#FFFFFF` | `#1C1A16` | 卡片、浮层 | — |
| `onSurface` | `#241F1A` | `#E8E1D6` | 标题、正文 | 15.17:1 / 14.40:1 |
| `onSurfaceVariant` | `#6B6055` | `#B5ABA0` | 次要信息、元数据 | 5.69:1 / 8.28:1 |
| `primary` | `#9C4A22` | `#E3A47C` | 主操作、进度、选中态 | 5.71:1 / 8.79:1 |
| `onPrimary` | `#FFFFFF` | `#45200C` | 主按钮文字 | 6.15:1 |
| `secondary`（苔绿） | `#55624F` | `#BACBA9` | 新章、在读、正向状态 | 6.01:1 |
| `tertiary`（藏金） | `#7A5A1E` | `#E0C078` | 榜单名次、评分星 | — |
| `outline` | `#D9CFBE` | `#3B352D` | 输入框、可交互边界 | 1.43:1（装饰线，非文本） |
| `outlineVariant` | `#E7DFD2` | `#4A4239` | 发丝分隔线 | 装饰，不作信息载体 |

规则：一块卡片最多一个强调色；强调色只出现在**一个主操作**和**一条进度**上。

### 2.2 颜色角色（阅读页，独立于外壳）

沿用 `ReaderPalette` 七槽，只调一个值：`dim` 从 `#7B6E5E` 改为 **`#6B5F50`**（米黄底 4.18:1 → 5.24:1，
页眉、进度、段评计数这些小字才过 AA）。

| 方案 | background | text | title | dim | accent | rule |
|---|---|---|---|---|---|---|
| 米黄 paper | `#F3EBD9` | `#2C2620` | `#1A1611` | `#6B5F50` | `#9C4A22` | `#E0D5BE` |
| 白 white | `#FFFFFF` | `#1F1D1A` | `#0C0B0A` | `#6E6252` | `#9C4A22` | `#E6E3DE` |
| 浅绿 mint | `#E4EEDE` | `#1E2820` | `#131C16` | `#5F6B60` | `#4A6B3F` | `#CBD8C4` |
| 夜色 dark | `#14120F` | `#E8E1D6` | `#F2ECE2` | `#B5ABA0` | `#E3A47C` | `#3B352D` |

### 2.3 字体阶梯

界面：Noto Sans SC；阅读正文：Noto Serif SC。字号沿用 `AppTypography`，补齐三个缺位：

| 角色 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| 页面大标题 | 28/36 | Bold | 书架、发现 |
| 区块标题 | 18/26 | Bold | 我的书架、为你推荐 |
| 卡片书名 | 14/20 | Medium | 网格封面下 |
| 元数据 | 12/18 | Normal | 作者、字数、章节名 |
| 徽标 | 11/15 | Medium | 新章、连载中 |
| 阅读正文 | 18–24/1.75 | Regular | 用户可调，基准 19sp |
| 阅读页眉 | 11/16 + 0.08em 字距 | Medium | 书名 · 章节 |

中文版心：左右各 20dp，段间距 0.75 行，首行缩进 2 字符（用全角空格实现，避免 `TextIndent` 在换行段落失效），
标题与正文间距 1.5 行。西文与数字统一用 `FontFeatureSettings` 的 `tnum`（指数、字数对齐）。

### 2.4 间距 / 圆角 / 层级

- `Space`：4dp 网格，页面边距统一 `gutter = 16dp`；区块之间 24dp，卡片之间 12dp，卡内 12dp。
- `Radius`：封面 8dp、卡片 14dp、浮层 18dp、抽屉 24dp。**同屏不超过两档圆角。**
- 层级：`flat = 0dp`（卡片，靠发丝线分隔）、`raised = 6dp`（抽屉、弹出菜单，靠遮罩而非阴影）。
- 图标：24dp 线性图标，统一 1.5px 描边，只用一个图标族（Material Symbols Outline），不带填充混排。

### 2.5 动效

| 场景 | 时长 | 曲线 | 说明 |
|---|---|---|---|
| 按下反馈 | 90ms | linear | 只改透明度，不改尺寸 |
| 页面进入 | 220ms | `FastOutSlowIn` | 右滑入 |
| 阅读 chrome 显隐 | 180ms | `FastOutSlowIn` | 顶/底栏同时淡入滑入 8dp |
| 设置抽屉 | 240ms | `FastOutSlowIn` | 底部上滑 |
| 翻页 | 250ms | 用户可选 | 仿真 / 滑动 / 无动画 |

`prefers-reduced-motion` / 系统「移除动画」开启时：全部改为 0ms 直切。

## 3. 分屏规格

### 3.1 书架（首页）

单列滚动，分区从上到下：

1. **页头**：28sp「书架」＋右侧搜索、设置两个 24dp 线性图标（触控区 48dp）。
2. **继续阅读**（唯一带颜色的卡片）：左 3:4 封面 56×75dp；右侧书名 16sp、`第 128 章 · 章节名` 12sp、
   62% 细进度条（2dp，赭石）、`继续阅读` 小实心胶囊按钮。整卡可点，按钮只是视觉锚点。
3. **筛选行**：`全部 / 在读 / 追更 / 已读` 芯片，选中态为浅赭底 `#F5DED0` + 赭石字，未选中为发丝描边。
4. **我的书架**：区块标题＋右侧「编辑」文字按钮；3 列网格，封面 112×149dp（8dp 圆角），书名 14sp 一行半，
   右上角苔绿徽标 `新 3`；长按书卡弹出分组/删除菜单。
5. **为你推荐 / 新书 / 榜单**：横向封面条（每卡 96dp 宽）或榜单前三行；每个区块之间用发丝线 + 24dp 留白分隔。

空态：居中 96dp 线性插画（书架轮廓）＋「书架还是空的」＋「去发现」文字按钮。
加载：骨架屏封面占位（`surfaceVariant` 块，无动画闪烁）。

### 3.2 发现（榜单 + 分类）

- 顶部：圆角 14dp 搜索框（48dp 高，左侧放大镜）＋右侧筛选图标。
- 分段控制：`热榜 / 新书 / 完本 / 口碑`，选中项赭石文字 + 2dp 下划线。
- 榜单行：64dp 高，左侧衬线序号（前三名赭石，其余 `onSurfaceVariant`），56×75dp 封面，
  书名 16sp Medium，次行「作者 · 分类 · 连载中」12sp，右侧苔绿 `上升 12` 徽标；行间只放发丝线。
- 分类：两行胶囊芯片（玄幻/都市/历史/科幻/悬疑/言情/武侠/仙侠），16dp 行距。

### 3.3 书籍详情

- 顶部：返回 / 分享 / 更多三个图标，透明压在封面色带上。
- 封面区：背景是一块 24dp 高的纸色带（不用模糊大图，省内存也更「纸」），3:4 封面 120×160dp 居中，8dp 圆角。
- 书名 22sp 衬线；作者行 `墨尘 · 连载中`；评分/字数/分类拆成**三列数字块**（大号数字 + 11sp 标签，竖发丝线分隔），
  不再用 `·` 串成一行。
- 标签：三个描边芯片（东方玄幻 / 升级流 / 群像）。
- 主操作：全宽实心赭石 `开始阅读`（56dp 高）；次操作：全宽描边 `加入书架`（48dp 高）。
  `下载 / 前 20 章 / 听书` 收进「更多」菜单，不再平铺成第三、第四行按钮。
- 简介：3 行截断 + `展开`；目录：区块标题右侧「共 402 章」，预览 4 行，点标题进目录页。
- 书评：一张卡片展示平均分 + 两条短评，底部「查看全部 128 条」。

### 3.4 目录

吸顶头部（书名 + 正序/倒序切换），行高 48dp，当前章赭石文字 + 左侧 2dp 竖条；
已下载章右侧小图标；底部「定位到当前章」胶囊按钮悬浮在列表右下。

### 3.5 阅读页（核心）

- **无 Scaffold**，正文全出血；点击屏幕中部 60% 区域切换 chrome。
- 页眉：居中 11sp `归墟纪 · 第 128 章`，`dim` 色，只在正文顶部出现一次（滚动后隐藏）。
- 正文：左右 20dp，19sp/1.75，段间距 0.75 行，首行缩进 2 字符，`textAlign = Justify` 关闭（中文右侧参差更自然）。
- 段评：段落右缘 4dp 处一个 20dp 圆角气泡，显示评论数；点击弹出段评面板。
- 高亮：`accent` 的 20% 叠加，不用 `primary` 直接铺底。
- **常显细进度线**：底部 2dp 赭石进度条 + 右侧 `62%`（11sp）；章节位置 `128 / 402`。
- 顶栏（显隐）：返回、书名（省略号）、书签、更多。
- 底栏（显隐）：目录 / 设置 / 听书 / 夜间，四个 24dp 图标 + 11sp 标签。
- 设置抽屉：见 3.6。

### 3.6 阅读设置（底部抽屉，24dp 顶圆角）

从上到下五行，每行左侧 13sp 标签、右侧控件：

1. **字号**：`A-` 滑块 `A+`，范围 18–24sp，步进 1，滑块拇指赭石。
2. **行距**：分段控制 `紧凑 / 标准 / 宽松`（1.5 / 1.75 / 2.0）。
3. **背景**：四个 32dp 圆形色板（米黄/白/浅绿/夜色），选中项加 2dp 赭石外环 + 11sp 名称。
4. **翻页**：分段控制 `仿真 / 滑动 / 无动画`。
5. **听书**：说明文字 + 开关。

抽屉开启时阅读页降为 60% 遮罩，正文不可点。所有控件触控高度 ≥48dp。

## 4. 可访问性与触控

- 触控目标 ≥48×48dp；图标视觉 24dp，热区用 `Modifier.minimumInteractiveComponentSize()` 撑开。
- 正文对比度：米黄 12.59:1、夜色 14.40:1、浅绿 12.75:1；次要文字全部 ≥4.5:1（见 2.2 修正）。
- 图标按钮带 `contentDescription`；纯装饰图标 `contentDescription = null`。
- 阅读正文支持系统字体缩放到 1.3× 不截断（`sp` + 自适应行高）。
- 声音/朗读状态用文字 + 颜色双通道，不只靠颜色。
- 缩放/旋转：横屏书架 4 列，阅读正文加宽到 32dp 边距，行宽不超过 40 字符。

## 5. 与现有实现的差异（落地清单）

| 位置 | 现状 | v2 要求 |
|---|---|---|
| `Theme.kt` | 令牌基本齐备 | 新增 `Space.section = 24.dp`；`Radius` 收敛为 8/14/18/24 四档 |
| `ReaderPalette.kt` | `Paper.dim = #7B6E5E`（4.18:1） | 改为 `#6B5F50`（5.24:1） |
| `ShelfScreen.kt` | 热词裸顶、书架与推荐同一网格 | 首页五段式：页头 / 继续阅读卡 / 筛选 / 书架网格 / 推荐区；热词移入「热搜」区块并加标题 |
| `DetailScreen.kt` | 三个等宽按钮平铺、元信息用 `·` 串 | 单一实心主 CTA + 描边次 CTA；元信息拆三列数字块；目录预览加「共 N 章」 |
| `ReaderScreen.kt` | 顶栏含 A-/A+，无设置抽屉 | 字号迁入设置抽屉；顶栏降为 4 个动作；加常显进度线与段评气泡 |
| `Components.kt` | 卡片依赖 `surfaceVariant` 与阴影混用 | 卡片统一「白面 + 发丝线 + 0 阴影」；新增 `MetaStat`、`RankRow`、`ProgressHairline` 三个组件 |
| `SettingsSheet.kt` | 全局设置与阅读设置混在一起 | 阅读相关五项拆到阅读页抽屉，全局设置只留同步/缓存/关于 |

## 6. 验收清单

- [ ] 每个页面左右边距都是 16dp，区块间距 24dp，无 13/18/34 之类散值
- [ ] 同屏圆角不超过两档，卡片无投影
- [ ] 所有次要文字对比度 ≥4.5:1（含阅读页页眉与进度）
- [ ] 触控目标 ≥48dp，图标 24dp / 1.5px 描边，无双族图标混排
- [ ] 阅读页 chrome 默认隐藏，点击中部可显隐，隐藏后正文高度增加
- [ ] 四种阅读底色切换时，顶栏/底栏/进度线同步换色，不出现「白底黑字夹深色正文」
- [ ] 系统字体放大 1.3×、横屏、减少动画三种状态均不破版
- [ ] 书架空态、加载态、错误态都有明确视觉，且错误态可重试
